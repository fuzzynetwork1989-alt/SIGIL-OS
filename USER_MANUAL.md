## Getting Started

### Installation

#### Windows

1. Download the SIGIL OS installer (`.exe` file)
2. Double-click the installer
3. Follow the simple setup wizard
4. Launch SIGIL OS from your desktop or Start menu

#### macOS

1. Download the SIGIL OS installer (`.dmg` file)
2. Open the downloaded file
3. Drag SIGIL OS to your Applications folder
4. Launch SIGIL OS from Applications

#### Linux

1. Download the SIGIL OS package (`.AppImage` file)
2. Make the file executable: `chmod +x SIGIL-OS.AppImage`
3. Run the application: `./SIGIL-OS.AppImage`

### First Launch

When you first launch SIGIL OS, you'll see a friendly onboarding screen that introduces you to the key features. Click "Get Started" to begin using your AI companion.

## Privacy & Security

### Your Data, Your Control

SIGIL OS is designed with privacy as a fundamental principle:

- **Local Storage by Default** - All your data is stored on your device
- **No Cloud Sync** - Your conversations don't leave your computer unless you enable it
- **No Telemetry by Default** - We don't collect usage data unless you opt in
- **Open Source** - The code is fully inspectable for transparency

### Data Storage

- **Conversations** - Stored locally in encrypted format
- **Memories** - Stored locally with importance scores
- **Missions** - Stored locally with progress tracking
- **Settings** - Stored locally on your device

### Deleting Your Data

To delete all your data:
1. Go to Settings
2. Scroll to "Data Management"
3. Click "Delete All Data"
4. Confirm the deletion

**Warning:** This action cannot be undone.

## Troubleshooting

### SIGIL OS Won't Start

**Problem:** Application doesn't open when double-clicked

**Solutions:**
- Make sure you've completed the installation
- Try restarting your computer
- Check if your antivirus is blocking the application
- Reinstall SIGIL OS

### "API Connection Error"

**Problem:** Message says "Could not connect to API server"

**Solutions:**
- This is normal if you're using SIGIL OS without the backend
- SIGIL OS will still work in offline mode with basic features
- For full features, ensure the SIGIL OS backend is running
- Check your internet connection

### Avatar Not Appearing

**Problem:** Avatar display is blank or missing

**Solutions:**
- Try refreshing the application
- Go to Avatar settings and reselect your preferences
- Restart the application

### Changes Not Saving

**Problem:** Settings or customizations aren't saved

**Solutions:**
- Make sure you have write permissions to the SIGIL OS folder
- Check if your disk has available space
- Try restarting the application

## FAQ

### Is SIGIL OS free?

Yes, SIGIL OS is free and open source.

### Does SIGIL OS require an internet connection?

SIGIL OS works best with an internet connection for full features, but basic functionality works offline.

### Can I use SIGIL OS on multiple devices?

Currently, SIGIL OS is designed for single-device use. Multi-device sync is planned for a future update.

### How does Dream Weaving work?

Dream Weaving is SIGIL OS's self-evolving system. It learns from your conversations and gradually improves its responses to better match your preferences and needs. All changes are logged and can be reviewed in the Dream Weaving dashboard.

### Is my data private?

Yes. By default, all your data is stored locally on your device. We don't collect telemetry unless you opt in, and we never share your data with third parties.

### Can I export my data?

Data export functionality is planned for a future update.

### How do I report bugs or request features?

You can report bugs and request features through our GitHub repository: https://github.com/fuzzynetwork1989-alt/SIGIL-OS/issues
