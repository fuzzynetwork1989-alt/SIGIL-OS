Core Features

🔐

Cryptographic Warrants

Every cognitive act is signed, timestamped, and verifiable using Ed25519 cryptography.

  • Provenance tracking for all actions
  • Reversible operations via rollback keys
  • Device-attested identity
  • No static secrets or API keys
🧠

Dream Weaving™

Self-evolving cognitive system that learns from conversations while maintaining full control.

  • Controlled evolution with approval
  • Complete rollback capability
  • Bias detection and correction
  • Auditable evolutionary history
🤖

TrueHD Avatar Assistant

Lifelike digital avatar with real-time emotion expression and lip-syncing.

  • Customizable appearance
  • Real-time emotion display
  • Voice interaction
  • Context-aware responses
🎨

Beautiful Customizable UI

Stunning interface with 5 themes and smooth animations.

  • 5 beautiful themes
  • Custom avatar morphing
  • Intuitive controls
  • Responsive design
🥽

Meta Quest 3 MR

Full mixed reality experience with spatial anchors and hand tracking.

  • Spatial anchors
  • Hand gesture controls
  • Passthrough mode
  • Voice assistant integration
🔒

Privacy-First Design

All data stored locally by default with optional cloud sync.

  • Local processing by default
  • No telemetry without consent
  • Open-source code
  • Full transparency

Personalized learning companion that adapts to your learning style and tracks progress with cryptographic provenance.

Scenario

A student uses SIGIL OS to learn programming. The AI adapts explanations based on their progress, every learning milestone is cryptographically signed, and the student can roll back to previous knowledge states if needed.

Career guidance and skill development with auditable learning paths and reversible decisions.

Installation

Windows Installation

# Step 1: Install prerequisites (run as Administrator)
install-prerequisites.bat

# Step 2: Setup environment
setup-environment.bat

# Step 3: Build and run
build-and-run.bat

For detailed instructions, see COMPLETE_SETUP_GUIDE.md

Linux Installation

# Step 1: Install dependencies
make install-deps

# Step 2: Setup environment
make setup-env

# Step 3: Build and run
make run

For detailed instructions, see COMPLETE_SETUP_GUIDE.md

macOS Installation

# Step 1: Install dependencies
make install-deps

# Step 2: Setup environment
make setup-env

# Step 3: Build and run
make run

For detailed instructions, see COMPLETE_SETUP_GUIDE.md

Docker Installation

# Build and run with Docker Compose
docker-compose up -d

For detailed instructions, see COMPLETE_SETUP_GUIDE.md
